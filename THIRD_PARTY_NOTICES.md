# Provenance

## Local prompt-tool interface and Krea instructions

The interface design tokens, visual structure, Krea examples and Krea prompt instructions were ported from the user's local `/Users/lisa/src/h3-prompt-tool`. That source folder is unchanged. Its CSS identifies minimaxh3tutorial.com as its design source; this project does not make a new licensing claim about that design.

## Official MiniMax guides

The guide files under `guides/` retain their existing content and provenance. See `guides/README.md`. Community recipes do not replace the official guide syntax.

## Video analysis workflow

Duration-aware frame inspection, small overlapping observation batches, targeted resampling, and shot/continuity review were adapted from the workflow described in [LoveRain1997/video-to-h3-prompt](https://github.com/LoveRain1997/video-to-h3-prompt). The application implementation is new JavaScript code. Its audio-content guesses and inconsistent retention/timestamp examples were not adopted.

## Storyboard planning guidance

Advisory planning principles (readable action beats, observable performance, camera/eyeline planning, and continuity review) were adapted from [phileiny/h3-storyboard-skill](https://github.com/phileiny/h3-storyboard-skill), reviewed 2026-08-30. The implementation is new JavaScript using the app's existing providers. No upstream skill is installed or executed, and no Claude Code integration is present. The author's corrected attribution and uncertainty notes are respected: dialogue is not required for expressions, and experimental numeric thresholds are not treated as official constraints.
